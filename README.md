# 2026 컴활 1급 시나공 학습 웹앱

2026년 컴퓨터활용능력(컴활) 1급 5차 시험 대비를 위한 **단일 파일(Single File) 학습 웹 애플리케이션**입니다.
시나공 교재의 '핵심 요약' 스타일로 정리한 개념 노트, 기출·예상 문제 풀이, 모의고사, 오답노트까지 하나의 HTML 파일로 제공되어
복사·붙여넣기 또는 바로 열기만으로 사용할 수 있습니다.

## 📁 파일 구조

| 파일 | 설명 |
|------|------|
| `index.html` | **전체 앱(HTML + CSS + JavaScript)**. 이 하나면 됩니다. |

외부 라이브러리·프레임워크·CDN 의존성 **0개**. HTML5 + CSS3 + Vanilla JS(web 표준)만으로 구성했습니다.

## 🚀 실 방법

1. **직접 실행**: `index.html`을 브라우저(Chrome/Edge/Safari/Firefox)로 더블클릭해 열기
2. **로컬 서버**: `npx serve` 또는 `python3 -m http.server` 후 브라우저에서 열기
3. **GitHub Pages**: 이 저장소를 Pages로 배포하면 웹에서 바로 사용 가능

## ✨ 기능

### 1. 시나공 스타일 핵심 요약 노트 (29개 카드)
- **컴퓨터 일반(11)**: 수치 체계, 하드웨어 성능, 데이터 통신, 인터넷·웹, 운영체제, DB 기초, 네트워크, 클라우드·신기술, 정보 보안, 멀티미디어, 프로젝트 관리
- **스프레드시트 일반(9)**: 참조 방식, 조건부 서식, 고급 필터, 테이블, 피벗, 핵심 함수(통계/lookup/문자열/날짜), 배열 수식·What-if, VBA 매크로
- **데이터베이스 일반(9)**: Access 객체, 데이터 형식, 관계·무결성, 선택 쿼리, 동적·크로스탭 쿼리, SQL, 폼, 보고서, 매크로·모듈
- 카드당 **핵심 개념 + ★ 필수 암기 + ⚠ 오답 피하기 Tip** 구성
- 키워드 검색, 읽음 체크(진도율 반영)

### 2. 기출·예상 문제 풀이 (38문항)
- 2026 출제 기준(5차) 수준 **4지선다 28 + O/X 10**
- 과목·유형·순서(순서/무작위)·범위(전체/**틀린 문제만**) 설정
- 선택 즉시 **정답 판정 + 시나공 스타일 상세 해설**
- 키보드 단축키: `1~4`(또는 `O`/`X`)로 선택, `Enter` 다음 문제

### 3. 2026 모의고사 (필기 시뮬레이션)
- 실제 과목 비중(25:15:15) 반영: **컴퓨터 10 + 스프레드시트 6 + DB 6 = 22문제 / 15분**
- 응시 중 정답 비노출, 문제 이동 내비게이션, 남은 시간 3분부터 경고
- 종료 시 **과목별 60% + 전체 60%(14점)** 합격 판정 + 문항별 정답 해설
- 모의고사 정답 기록도 오답노트에 자동 반영

### 4. 학습 진도율 · 오답노트 (localStorage)
- 문제 풀이 진도, 요약 노트 독서 진도, 누적 정답률을 상단·통계 화면에서 확인
- **오답노트**: 마지막 풀이를 틀린 문제만 자동 수집 → 오답 전용 연습 → 정답으로 만들면 자동 제거
- 모의고사 기록(최근 10회), 전체 데이터 초기화

> 데이터는 브라우저 `localStorage`에 저장됩니다 (계정 불필요, 기기의 브라우저마다 별도 저장).

## 📝 시험 구조 참고 (5차 기준)

| 구분 | 구성 |
|------|------|
| 필기 | 컴퓨터 일반 25 + 스프레드시트 일반 15 + 데이터베이스 일반 15 = 55문항 / 100분, 과목별·전체 60% 이상 |
| 실기 | 스프레드시트 + 데이터베이스 각 2문항 / 60분, 과목별 250점·전체 500점 기준 80% 이상 |

본 앱은 **필기(3과목) 학습**에 집중하며, 실기 핵심 개념(엑셀 함수·VBA, Access 쿼리·폼·보고서)은 요약 노트와 문제에 반영했습니다.

## 🧱 데이터 구조 (localStorage)

```
comp1_2026_app_v1 = {
  v: 1,
  cards: { "<과목>-<카드번호>": 타임스탬프 },        // 읽은 요약 카드
  rec:   { "q<문제번호>": { c, w, last, at } },     // c=누적 정답, w=누적 오답, last=마지막 정(1)/오(0)
  exams: [ { at, score, pass, secs, subs, auto } ]  // 모의고사 기록(최대 10회)
}
```
