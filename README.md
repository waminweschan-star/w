# 2026 컴활 1급 교과서 (Textbook) 학습 웹앱

2026년 컴퓨터활용능력(컴활) 1급 5차 시험 대비를 위한 **단일 파일(Single File) 교과서형 학습 웹 애플리케이션**입니다.
3과목(컴퓨터 일반 · 스프레드시트 · 데이터베이스)을 **205페이지 분량의 교과서**로 정리하고,
진짜 책처럼 **페이지를 넘기며** 읽을 수 있습니다. 문제 연습·모의고사·오답노트·학습 기록도 함께 제공합니다.

> 디자인: **흑백(단색) 위주의 절제된 교과서 스타일** — 종이 페이지, 장/절/페이지 번호, 목차 드로어, 페이지 진행 바.

## 📁 파일 구조

| 파일 | 설명 |
|------|------|
| `index.html` | **전체 앱(HTML + CSS + JavaScript + 교재 데이터)**. 이 하나면 됩니다. |

외부 라이브러리·프레임워크·CDN 의존성 **0개**. HTML5 + CSS3 + Vanilla JS(web 표준)만으로 구성했습니다.

## 🚀 실행 방법

1. **직접 실행**: `index.html`을 브라우저(Chrome/Edge/Safari/Firefox)로 더블클릭해 열기
2. **로컬 서버**: `python3 -m http.server` 후 브라우저에서 열기
3. **GitHub Pages**: 이 저장소를 Pages로 배포하면 웹에서 바로 사용 가능

## ✨ 기능

### 1. 교과서 (205페이지, 3권 + 서문)
- **서문**(2p): 이 책의 목적·활용법, 2026 시험 안내·공부법
- **1권 컴퓨터 일반**(65p): 역사·분류 / 하드웨어 / 수치 체계 / 운영체제 / 데이터 통신 / 인터넷·웹 / 정보 보안 / 신기술 / 프로젝트 관리·표준화
- **2권 스프레드시트·엑셀**(70p): 개요 / 데이터 입력·편집 / 서식 / 정렬·필터·테이블 / 함수 1(기본·통계·논리) / 함수 2(조회·참조·문자열) / 차트·데이터 분석 / 배열 수식·동적 배열 / VBA 매크로
- **3권 데이터베이스·액세스**(65p): DB 개념 / 테이블 설계 / 관계·무결성 / 선택 쿼리 / 동적·크로스탭 쿼리 / SQL / 폼 / 보고서 / 매크로·모듈
- **페이지 넘김**: `← 이전 / 다음 →` 버튼 + 키보드 `←` `→` (교과서 탭에서), 상단 `n / 205` 페이지 표시
- **목차 드로어**: 우측 상단 `☰ 목차` → 권 → 장 → 절 → 페이지까지, **본문 포함 페이지 검색**, 읽은 페이지 ✓ 표시
- 페이지 구성: 장 제목 헤더, 절 제목, **노트**(핵심 정리)·**출제 포인트**·**수식/코드 블록**·표, 하단 페이지 번호
- 읽은 페이지가 **읽기 진도**로 자동 기록됩니다

### 2. 문제 연습 (38문항)
- 2026 출제 기준(5차) 수준 **4지선다 28 + O/X 10**
- 과목·유형·순서(순서/무작위)·범위(전체/**틀린 문제만**) 설정
- 선택 즉시 **정답 판정 + 시나공 스타일 상세 해설**
- 키보드 단축키: `1~4`(또는 `O`/`X`)로 선택, `Enter` 다음 문제

### 3. 2026 모의고사 (필기 시뮬레이션)
- 실제 과목 비중(25:15:15) 반영: **컴퓨터 10 + 스프레드시트 6 + DB 6 = 22문제 / 15분**
- 응시 중 정답 비노출, 문제 이동 내비게이션, 남은 시간 3분부터 경고
- 종료 시 **과목별 60% + 전체 60%(14점)** 합격 판정 + 문항별 정답 해설
- 모의고사 정답 기록도 오답노트에 자동 반영

### 4. 학습 기록 · 오답노트 (localStorage)
- **교과서 독서 진도**(읽은 페이지), 문제 풀이 진도, 누적 정답률을 상단·통계 화면에서 확인
- **오답노트**: 마지막 풀이를 틀린 문제만 자동 수집 → 오답 전용 연습 → 정답으로 만들면 자동 제거
- 모의고사 기록(최근 10회), 전체 데이터 초기화

> 데이터는 브라우저 `localStorage`에 저장됩니다 (계정 불필요, 기기의 브라우저마다 별도 저장).

## 📝 시험 구조 참고 (5차 기준)

| 구분 | 구성 |
|------|------|
| 필기 | 컴퓨터 일반 25 + 스프레드시트 일반 15 + 데이터베이스 일반 15 = 55문항 / 100분, 과목별·전체 60% 이상 |
| 실기 | 스프레드시트 + 데이터베이스 각 2문항 / 60분, 과목별 250점·전체 500점 기준 80% 이상 |

본 앱은 **필기(3과목) 학습**에 집중하며, 실기 핵심 개념(엑셀 함수·VBA, Access 쿼리·폼·보고서)은 2·3권 본문과 문제에서 다룹니다.
